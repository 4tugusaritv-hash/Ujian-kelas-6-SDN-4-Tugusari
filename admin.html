Pengaturan Soal & Bobot Nilai

Bobot Nilai Mapel Ini Total: 100%
Pilih Cepat:

Mendukung format tag [SOAL], [A]-[D], [ISIAN], [ESSAY], [KUNCI], nomor biasa, maupun tabel Word.

Panduan Input & Edit Cepat:

  • PG (1 Benar): Klik salah satu huruf A / B / C / D.
  • PGK (Benar > 1): Ubah tipe soal menjadi PGK, lalu klik 2 atau lebih huruf kunci.
  • Isian vs Essay: Klik Ubah Isian ↔ Essay di kanan atas jika bagian uraian ingin dinilai sebagai Essay (skor 0–10).
  • Tambah Gambar Manual: Klik tombol + Gambar pada kartu soal untuk menyisipkan gambar dari perangkat.

Pratinjau & Input Kunci / Editor Butir Soal

Periksa soal, gambar, tipe (PG, PGK, ISIAN, ESSAY), dan kunci jawaban sebelum menyimpan.

Pilih Mata Pelajaran, atur bobot nilai, lalu unggah file .docx atau klik Muat Soal Tersimpan dari Server.
